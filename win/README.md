# Файлы программы для Windows

Здесь лежат готовые `.exe` — по папке на версию: отсюда их берёт процесс
«Публикация выпуска» и прикладывает к выпуску.

Папка несёт версию, а файл внутри называется просто `Flinks.exe` — под этим
именем он и попадает на компьютер, и этим же именем подписан в описании
выпуска, по которому программа обновляет сама себя.
