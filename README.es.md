# Flinks

**Un archivo o un enlace, en un clic.** Un sitio web sin registro, una
aplicación para Android y un programa para Windows que coloca automáticamente
el enlace corto en el portapapeles.

## Qué es

Dos tareas que suelen resolverse con servicios distintos, aquí reunidas en uno:

| | |
|---|---|
| 📎 | **Archivo → enlace.** Arrastra y suelta para obtener una dirección corta que puedes compartir. Varios archivos se empaquetan en un archivo comprimido. |
| ✂️ | **Dirección larga → corta.** La misma dirección, pero legible y lo bastante corta para caber en un mensaje. |
| 📷 | **Enlace → código QR.** Para pasarlo al teléfono sin enviarlo en un mensaje. |

No hace falta registrarse: los invitados tienen acceso a todo, con límites más
modestos — archivos más pequeños y menos tiempo de almacenamiento. Un perfil
aumenta esos límites y añade una lista de tus archivos y enlaces.

## Aplicación para Android

- **Funciona desde Compartir («Поделиться»).** Puedes enviar un archivo o un
  enlace directamente desde cualquier otra aplicación — la galería, el gestor
  de archivos o el navegador — sin abrir Flinks.
- **Accesos directos en el icono.** Mantén pulsado el icono para ir directamente
  a «Загрузить файл» (Subir archivo), «Ссылка из буфера» (Enlace del
  portapapeles), «Сократить» (Acortar) o «Мои файлы» (Mis archivos).
- **No espera a otros sitios web.** Las fuentes y la herramienta de compresión
  están incluidas en el paquete, por lo que la página se carga incluso cuando
  no se puede acceder a otros dominios.
- **Se actualiza sola.** La propia aplicación avisa de las nuevas versiones,
  con su número, tamaño y lista de cambios; el gestor de descargas del sistema
  descarga el archivo.
- **Requiere** Android 7.0 o posterior. Unos 370 KB, sin publicidad ni
  rastreadores.

Descarga el archivo de la [página de versiones](../../releases) o
[del sitio web](https://links.iluh.in/update.php?a=download): está firmado con
la misma clave en ambos sitios, por lo que la actualización se instala sobre
la aplicación existente.

## Programa para Windows

No es una ventana con el sitio web: ya tienes un navegador a mano. El
programa elimina pasos innecesarios.

- **Arrastra los archivos a la ventana** y el enlace corto ya estará en el
  portapapeles.
- **Enviar a («Отправить») en el Explorador de archivos** hace lo mismo sin
  abrir la ventana.
- **Ctrl+Shift+L** convierte un enlace largo del portapapeles en uno corto.
- **Un solo archivo.** No necesitas instalar .NET ni bibliotecas adicionales;
  el programa comprueba si hay actualizaciones y se reemplaza a sí mismo.

Requiere Windows 10 o posterior, de 64 bits. El archivo está en la
[página de versiones](../../releases).

## iPhone y otros sistemas

No hay una aplicación independiente para iPhone, pero el sitio web es una PWA:
Compartir («Поделиться») → Añadir a pantalla de inicio («На экран „Домой“»)
añade un icono y permite abrirlo sin barra de direcciones. En Chrome para
Android y ordenadores, usa el menú «⋮» → Instalar aplicación
(«Установить приложение»).

## Historial de versiones

Todas las versiones con sus descripciones están en la
[página de versiones](../../releases): la aplicación para Android y el
programa para Windows tienen numeraciones independientes (`v1.7` y
`win-v1.4`). Los archivos más recientes siempre están en la
[última versión](../../releases/latest), y el sitio web ofrece esos mismos
archivos. Hay un resumen de todas las versiones [en la wiki](../../wiki/Versions).

## Qué contiene este repositorio

Solo las versiones y la descripción del servicio: notas de las versiones,
imagen de portada, icono y wiki. El código fuente del sitio web, la aplicación
para Android y el programa para Windows sigue siendo cerrado.
