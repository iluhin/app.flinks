# Приложение для Android

## Зачем оно, если есть сайт

Ради одной строчки в меню «Поделиться». Фотография из галереи, документ из
файлового менеджера, ссылка из браузера — «Поделиться» → Flinks, и через
секунду короткая ссылка уже в буфере обмена. Открывать сайт, искать вкладку и
выбирать файл не нужно.

Всё остальное — та же страница сервиса, что и в браузере.

## Как поставить

1. Скачайте `Flinks-<версия>.apk`
   [со страницы выпусков](../../releases/latest) или
   [с сайта](https://links.iluh.in/update.php?a=download).
2. Откройте скачанный файл. Android спросит разрешение ставить приложения из
   этого источника — это обычный вопрос для файла не из магазина.
3. Готово. Приложение появится в «Поделиться» и в меню приложений.

Нужен **Android 7.0** или новее.

## Меню на значке

Долгое нажатие на значок открывает четыре ярлыка:

| | |
|---|---|
| **Загрузить файл** | сразу откроется выбор файла |
| **Из буфера** | сократит ссылку, которая лежит в буфере обмена |
| **Сократить** | откроет поле для адреса |
| **Мои файлы** | список того, что вы отправляли |

Ярлыки появляются после первого запуска приложения, а не сразу после
установки.

## Обновления

О новой версии сообщает само приложение: номер, размер и список изменений.
Файл скачивает системный диспетчер загрузок, он же предлагает установку.
Приложение подписано одним и тем же ключом с первой версии, поэтому новая
встаёт поверх старой и ничего не теряет.

## Что внутри

Около 370 КБ. Внутри лежат шрифты и упаковщик архивов, которые страница иначе
тянула бы с чужих доменов, — поэтому интерфейс собирается, даже когда до них
не достучаться.

**Разрешений, которые надо выдавать руками, приложение не просит вовсе:** ни
камеры, ни контактов, ни геопозиции, ни установки пакетов. Рекламы и трекеров
нет.

## Заставка

Пока страница грузится, видно светлячка: он изредка машет крыльями и
разгорается. Это не картинка — значок разобран на слои и собирается на ходу,
поэтому выглядит одинаково на любом телефоне, какой бы формы значки ни были в
оболочке.

## Чего приложение не делает

- Не работает без сети: всё, кроме заставки, приходит с сервера.
- Не умеет продолжать загрузку после того, как его закрыли.
- Не открывает ссылки сервиса само — пока их открывает браузер.

Это известные ограничения, а не случайность; они записаны в план.
