# Windows 1.0 — короткая ссылка без лишних действий

Программа для Windows. Не окно с сайтом — на компьютере браузер и так под
рукой, — а способ обойтись без него:

- перетащите файлы в окно — короткая ссылка сразу окажется в буфере обмена;
- «Отправить» в Проводнике делает то же самое, не открывая окно;
- Ctrl+Shift+L превращает длинную ссылку из буфера в короткую.

Значок живёт в трее, закрытие окна прячет программу, а не выключает. Можно
добавить пункт в меню «Отправить» и включить запуск при входе в систему — всё
из меню значка.

Один файл, ничего доустанавливать не нужно: ни .NET, ни библиотек Visual C++.

**Windows покажет «Неизвестный издатель»** — файл не подписан. Нажмите
«Подробнее» → «Выполнить в любом случае». Подпись требует платного
сертификата, и своим ключом, как на Android, тут не обойтись.
