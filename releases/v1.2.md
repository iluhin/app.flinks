# 1.2 — файл и ссылка прямо из «Поделиться»

Теперь файл или ссылку можно отправить в сервис из любого другого приложения
через системное меню «Поделиться»: ссылка уходит в сокращатель, файл — в
загрузку, и сразу получается готовая короткая ссылка.

Заодно заработало то, что в прошлой версии в WebView просто не работало:

- кнопка выбора файла открывает системное окно — раньше загрузить файл из
  приложения было нельзя вовсе;
- скачивание идёт через системный диспетчер загрузок, с сессией профиля, строкой
  в шторке и файлом сразу в «Загрузках»;
- QR-код сохраняется картинкой в «Загрузки»;
- при пропавшей связи вместо пустого белого экрана — понятное сообщение с
  кнопкой «Повторить»;
- светлая и тёмная тема следуют настройке системы, как и на сайте.
