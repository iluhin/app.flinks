# 1.3 — заставка при запуске и обновления с GitHub

При запуске снова видно заставку: плитка со значком сервиса, название и полоса
загрузки вместо пустого тёмного экрана, из-за которого казалось, что приложение
не запускается. Полоса показывает настоящий ход загрузки страницы.

Обновления теперь ищутся сначала в релизах на GitHub, а если GitHub недоступен —
на сайте, как раньше. Ничего настраивать не нужно, приложение само выбирает
доступный источник.

Вернулось и то, что потерялось в 1.2:

- понятный экран при пропавшей связи, в оформлении сервиса и с кнопкой
  «Повторить», вместо системной страницы об ошибке;
- предупреждение, если не удалось проверить сертификат сайта — такое соединение
  приложение не открывает;
- кнопка «Позже» в окне обновления откладывает эту версию на трое суток, а не
  спрашивает при каждом запуске;
- если Android запрещает установку из приложения, оно подскажет, где включить
  разрешение;
- в окне загрузки обновления видно, сколько мегабайт скачано, и её можно
  отменить;
- русские имена скачанных файлов больше не искажаются.
