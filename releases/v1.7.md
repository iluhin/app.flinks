# 1.7 — Flinks

- **Новое имя и значок.** Приложение называется Flinks; значок — светлячок,
  тот же, что у программы для Windows и на сайте.
- **Светлячок на заставке живой.** Он сидит ровно, а раз в несколько секунд
  машет крыльями и разгорается — коротко, затухающей серией, как настоящий.
  Значок для этого разобран на слои: плитка, два крыла, брюшко, голова.
- Файл приложения теперь называется `Flinks-1.7.apk`.

Имя пакета осталось прежним (`com.iluhin.links`), поэтому обновление встанет
поверх установленного приложения, а не потребует удалять старое. Меню по
долгому нажатию на значок и всё остальное из 1.6 работает как работало.
