# 1.6 — новый значок и меню на значке

- **Новый значок.** Лист документа, правый край которого перетекает в петлю —
  файл и ссылка в одном знаке. Тот же, что у программы для Windows: теперь он
  один на весь сервис.
- **Меню по долгому нажатию на значок.** Четыре пункта, по которым сразу
  попадаешь куда нужно:
  - **Загрузить файл** — открывается системный выбор файла, без лишних
    нажатий;
  - **Из буфера** — ссылка из буфера обмена сокращается сама;
  - **Сократить** — открывается поле для адреса;
  - **Мои файлы** — страница профиля со своими файлами и ссылками.
- **Заставка при запуске** показывает настоящий значок приложения, а не
  похожий рисунок, — расходиться им теперь негде.

Пункты меню появляются после первого запуска приложения: так устроены
динамические ярлыки.
