# Пакеты приложения

Здесь лежат готовые APK: отсюда их берёт процесс «Публикация выпуска» и
прикладывает к выпуску. Исходный код закрыт, поэтому файл кладётся сюда
руками — иначе скачивать приложение было бы неоткуда.

Все пакеты подписаны одним и тем же ключом с самой первой версии, поэтому
новая версия встаёт поверх установленной.
